# OpenMesh

> **Status: 0.1.0** — released as a portable Windows x64 archive. The compiler is pre-1.0: the language, CLI, MCP, and
> output contracts may still change in a 0.x minor release. See [Changelog](docs/reference/changelog.md).

OpenMesh compiles an OML text file (`*.om`) into a 2D sketch or a 3D solid and exports glTF 2.0 binary (`.glb`),
OBJ, STL, 3MF, SVG, or DXF. A model is one text file: no binary project, no hidden state, no GUI required. The same
source and the same compiler version produce byte-identical output.

A model that is text can be reviewed as a diff, built in CI, cached by content hash, and generated by a model that has
no filesystem access. OML has no I/O, network, clock, environment variables, or reflection; `import` reads only `.om`
files inside the project root. A build is bounded by 10 s CPU, 512 MiB RAM, and 2 million triangles by default.

## Install

Windows x64, portable archive, no installer and no runtime:

```powershell
New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\OpenMesh" | Out-Null
Expand-Archive .\openmesh-0.1.0-windows-x64.zip -DestinationPath "$env:LOCALAPPDATA\OpenMesh" -Force
& "$env:LOCALAPPDATA\OpenMesh\openmesh.exe" version
```

Expected output: `openmesh 0.1.0 (oml 1.0)`.

The archive contains `openmesh.exe`, `docs/`, `LICENSE`, `README.md`, `SHA256SUMS.txt`, and `assets/icon.png`. Keep
`docs/` next to the executable: `openmesh docs` and the MCP documentation tools read it from disk. Verify the
executable against `SHA256SUMS.txt`; the SHA-256 of the archive is listed on the release page.

Linux x64 is supported by the compiler. No Linux archive is published with 0.1.0; build from source below.

## Build from source

Requires a stable Rust toolchain. The Windows icon is embedded through `rc.exe` when it is available; the build
succeeds without it.

```powershell
cargo build --release
cargo test --release
.\target\release\openmesh.exe version
.\target\release\openmesh.exe build examples\cube.om
```

`scripts\package.ps1` produces the portable archive and `SHA256SUMS.txt`. Two optional viewers are feature-gated so the
default build has no GUI dependency:

```powershell
cargo run --release --features viewer --bin openmesh-view -- --root . model.om
cargo run --release --features viewer-gpu --bin openmesh-view-gpu -- --root . model.om
```

## Quick start

```bash
openmesh build model.om -o model.glb    # compile and export
openmesh check model.om --json          # parse and typecheck, no geometry
openmesh mcp --root .                   # MCP server over stdio for LLM agents
```

Minimal model, `model.om`:

```om
// @om 1
@param size = 40mm { min = 10mm, max = 100mm, step = 1mm, desc = "Cube edge" }

export(box([size, size, size]), "cube.glb");
```

## Capabilities

| Area | Supported |
|---|---|
| 3D primitives | `box`, `sphere`, `cylinder`, `cone`, `torus`, `polyhedron` |
| 2D primitives | `rect`, `circle`, `polygon` (with holes), `path` |
| Booleans | `union(list)`, `difference`, `intersection`, `hull`, `minkowski` |
| 2D to 3D | `extrude` (twist, slices, taper), `revolve`, `sweep`, `offset` |
| Modifiers | `fillet`, `chamfer`, `shell`, `array`, `subdivide` |
| Selectors | `edges` / `faces` with presets (`"vertical"`, `"top"`) and predicates |
| Parameters | `@param` ranges and steps, `@preset` configurations, `--param` overrides |
| Preview | deterministic CPU contact sheet and single view; optional GPU viewport with orbit and sliders |
| Appearance | `Color` per exported solid, written to glTF, OBJ/MTL, 3MF, SVG |
| Output | `.glb`, `.obj`, `.stl`, `.3mf`, `.svg`, `.dxf` |

## Not supported

OpenMesh does not sculpt, rig, animate, produce cinematic renders, or simulate. It has no NURBS or class-A surface
modeling, no brush texturing, and no GUI sketching with mouse constraints. `fillet` is faceted and skips concave or
knife edges; `chamfer` works on convex edges. Boolean operations can produce a non-manifold result when two solids
touch only along an edge or a face; the compiler reports `E0307` instead of writing a broken mesh. The full list is in
[Limits](docs/language/13-limits.md).

## Кратко по-русски

OpenMesh — компилятор текстовых моделей на языке OML (`.om`) в 2D-эскиз или 3D-сетку. Модель — один
текстовый файл в git; сборка детерминирована, GUI не требуется. Поддерживаются примитивы, булевы
операции, выдавливание, вращение, оболочка, параметры и экспорт в glTF/OBJ/STL/3MF/SVG/DXF. Установка —
распаковать архив и запустить `openmesh build model.om -o model.glb`. Документация на английском,
начиная с [установки](docs/start/01-install.md).
